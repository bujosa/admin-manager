# Contributing

Create a topic branch, keep changes focused, and run `swift test` followed by
`make build XCODEBUILD_FLAGS=CODE_SIGNING_ALLOWED=NO` before opening a pull request.
Use Conventional Commits. Do not attach real device inventories, credentials,
terminal output from private servers, or unredacted screenshots to issues/PRs.
Review UI changes manually with synthetic devices; do not add automated UI tests.
